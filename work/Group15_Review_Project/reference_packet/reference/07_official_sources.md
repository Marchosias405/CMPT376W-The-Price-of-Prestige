Current editor-reference workflow checked during planning:
- New story: Story > New.
- Format: Story > Details.
- Styles: Story > Stylesheet.
- Review: Build > Play or Build > Test.
- Export playable HTML: Build > Publish to File.
- Import: Library > Import from the story library.
- Browser storage is local to a browser/profile; exported HTML is a useful backup.
- A Twee file is editable source, not a playable submission by itself.
