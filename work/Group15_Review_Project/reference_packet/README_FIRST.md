# Group 15 Codex handoff

This packet contains the brief and source material needed for Codex to build **The Price of Prestige**, a CMPT 376W ethical case study in Twine. It is a handoff packet, not the finished game or final design submission.

## What to do

1. Extract this ZIP.
2. Make the extracted CMPT376W_Group15_Codex_Handoff folder available as Codex's working/project folder.
3. Paste the contents of START_PROMPT.txt into Codex.
4. Codex should read CODEX_TASK.md and every reference, then build, test, and deliver the project in work/.
5. Review the completed HTML, PDF, preview screenshots, and test report.
6. Supply real team contribution percentages and perspective examples before treating the design PDF as final.

You do not need to complete the earlier screenshot-by-screenshot coaching setup before using this packet.
